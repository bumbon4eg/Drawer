# Проект: Упрощённый Paint (Graphic Editor)

Данный проект представляет собой упрощённую версию графического редактора, разработанную в учебных целях. Приложение позволяет создавать прямоугольники и эллипсы, выбирать цвет и тип заливки, перемещать уже нарисованные фигуры, а также отменять и возвращать действия с помощью механизма undo/redo. Основная цель проекта – демонстрация применения и взаимодействия различных паттернов проектирования на практике.

---

## Основные функции

- **Создание фигур** – рисование прямоугольников и эллипсов с помощью мыши (зажатие и растягивание).
- **Выбор цвета** – установка цвета контура и заливки через диалоговое окно.
- **Тип заливки** – фигуры могут быть залиты цветом или быть прозрачными.
- **Перемещение фигур** – захват и перетаскивание существующих фигур мышью.
- **Отмена/возврат действий** – полноценный механизм undo/redo с ограничением истории (до 50 действий).
- **Интерфейс** – меню и панель инструментов для доступа ко всем функциям.

---

## Используемые паттерны проектирования

В проекте активно применяются следующие паттерны:

| Паттерн | Описание применения |
|---------|----------------------|
| **Singleton** | `Controller` и `MenuCreator` реализованы как одиночки для глобального доступа к основным компонентам. |
| **Observer** | `Model` наследует `Observable` и уведомляет `MyPanel` (наблюдатель) об изменениях, что вызывает перерисовку. |
| **Strategy** | Поведение заливки (`FillBehavior`) вынесено в отдельные классы (`Fill`, `NoFill`), что позволяет легко изменять алгоритм отрисовки. |
| **State** | Механизм undo/redo управляется через состояния (`UndoRedoState`), определяющие доступность кнопок и переходы между состояниями. |
| **Command** | Действия пользователя (рисование, перемещение) инкапсулированы в классы, реализующие интерфейс `AppAction` с поддержкой execute/unexecute. Меню и панель инструментов используют `AppCommand` для обработки команд. |
| **Factory Method** | `ShapeType` (enum) определяет фабричный метод `createShape`, создающий конкретные фигуры. `MyShapeFactory` предоставляет удобный способ создания фигур с учётом текущего состояния. |
| **Prototype** | `AppAction` и `MyShape` поддерживают клонирование (`cloneAction` и `clone`) для сохранения состояния действий при undo/redo. |
| **MVC** | Архитектура разделена на модель (`Model`), представление (`MyPanel`, `MyFrame`) и контроллер (`Controller`), что обеспечивает слабую связанность. |

## Технологии

- **Язык**: Java (версия 8+)
- **Графический интерфейс**: Swing
- **Сборка**: (предполагается использование Maven или Gradle; для удобства можно добавить зависимость Lombok)
- **Утилиты**: Lombok (для генерации геттеров/сеттеров)

---

## Запуск проекта

### Требования
- Установленная Java (JDK 8 или выше)
- (Опционально) Система сборки Maven/Gradle, если проект организован соответствующим образом

### Инструкция
1. Склонируйте репозиторий или скопируйте исходные файлы.
2. Убедитесь, что библиотека Lombok подключена (если используется). В большинстве IDE достаточно установить плагин и включить аннотационную обработку.
3. Скомпилируйте проект и запустите класс `BootClass`, содержащий метод `main`.

Пример запуска из командной строки (при условии, что все классы скомпилированы):
```bash
java org.example.BootClass
```

Если проект собирается через Maven, выполните:
```bash
mvn clean compile exec:java -Dexec.mainClass="org.example.BootClass"
```

## Структура проекта (основные пакеты)

- `org.example` – точка входа (`BootClass`).
- `org.example.controller` – контроллер, состояние меню, машина undo/redo.
- `org.example.controller.actions` – реализации действий (рисование, перемещение).
- `org.example.controller.state` – состояния undo/redo.
- `org.example.model` – модель данных, фигуры, фабрики, поведение заливки.
- `org.example.model.fill` – стратегии заливки.
- `org.example.model.shape.factory` – фабрика и перечисление типов фигур.
- `org.example.view` – графический интерфейс (окно, панель).
- `org.example.view.menu` – создание меню, командные классы для обработки пользовательских действий.

---

## Примечания

- Механизм undo/redo сохраняет состояния действий только для операций рисования и перемещения. Каждое действие хранит необходимые параметры (координаты, ссылку на фигуру) и может быть отменено или повторно выполнено.
- При создании новой фигуры история redo очищается, что соответствует стандартному поведению undo/redo.
- Интерфейс адаптирован для работы с мышью: нажатие – начало действия, перетаскивание – изменение параметров, отпускание – завершение и добавление в историю.
